# Paper Concepts

<!-- impeccable:product-schema 1 -->

## Platform

web

The interface operates in the Obsidian desktop application.

## Stack

The plugin uses TypeScript and the native Obsidian controls.

## Users

Researchers import academic PDFs into an Obsidian vault that they have.

## Product Purpose

The plugin changes papers into linked Paper notes and Concept notes. It uses an AI harness that the user installed on the computer.

## Capabilities and Constraints

The user selects one knowledge folder. The default PDF parser is local text extraction. MinerU is an option that the user must select.

The plugin supports Codex, Claude Code, and OpenCode. It uses the login of the harness.

The plugin saves the results automatically. It adds new information from the paper to existing Concepts.

The user can edit four prompt templates. The plugin keeps the prompt version of each job.

## Brand Commitments

The interface must use the native Obsidian controls. The interface uses the colors of the active theme.
